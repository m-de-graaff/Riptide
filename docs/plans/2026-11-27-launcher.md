# Launcher Implementation Plan

**Goal:** A dark, tabbed launcher window that edits `%APPDATA%\Riptide\riptide.toml`, runs preflight checks and starts the runtime once it exists. Design: `docs/design/2026-11-27-launcher.md`.

**Architecture:** `riptide-config` (pure settings library) ← `riptide-preflight` (machine facts and their judgement) ← `riptide-launcher` (egui window). Logic that can be tested lives outside the window code.

**Tech stack:** Rust 1.97.1, edition 2024, `serde` 1, `toml` 1.2, `eframe` 0.37 (glow backend), `rfd` 0.18 (folder dialog), `windows` 0.62.2.

This plan is executed in the same session it was written in, so it lists tasks, interfaces and tests, and the code is in the repository rather than repeated here.

## Global Constraints

- No environment variables or flags for settings; `riptide.toml` is the only source.
- Workspace lints apply; every `unsafe` block has a `// SAFETY:` comment.
- `cargo test --workspace` and `cargo clippy --workspace --all-targets -- -D warnings` pass.
- No game artwork or game files in the repository.

## Task 1: `riptide-config`

**Files:** `crates/riptide-config/{Cargo.toml,README.md,src/lib.rs}`

**Produces:** `Settings { game: Game, display: Display, performance: Performance }`, `ConsoleMode`, `WindowMode`, `MissingPipeline`, `Resolution`, `Settings::problems() -> Vec<String>`, `default_path() -> PathBuf`, `load(&Path) -> Result<Settings, ConfigError>`, `save(&Path, &Settings) -> Result<(), ConfigError>`, `set_aside(&Path) -> io::Result<PathBuf>`.

**Tests:** missing file gives defaults; defaults are borderless, HDR on, promotion on; save then load is equal and leaves no temporary file; file uses snake_case names; keys left out keep defaults; an unknown key is a parse error naming the key; a broken file can be set aside; out-of-range values are reported.

## Task 2: `riptide-preflight`

**Files:** `crates/riptide-preflight/{Cargo.toml,README.md,src/lib.rs,src/windows.rs}`

**Consumes:** `riptide_config::Settings`.

**Produces:** `Level { Ok, Warning, Blocking }`, `Check { id, level, title, detail }`, `Machine { free_ram_mib, commit_headroom_mib, gpu: Option<String>, power_saver: Option<bool>, game_folder_exists: Option<bool>, runtime_present }`, `judge(&Machine, &Settings) -> Vec<Check>`, `can_play(&[Check]) -> bool`, `summary(&[Check]) -> String`, `gather(&Settings, runtime: &Path) -> Machine`.

**Tests:** a good machine has no warnings but the missing runtime; no folder blocks; low RAM warns, very low RAM blocks; a custom RAM budget moves the threshold; too little page-file room blocks; no GPU blocks; power saver warns; out-of-range settings block; `summary` counts each level; `gather` runs on this machine and reports non-zero RAM.

## Task 3: `riptide-launcher`

**Files:** `crates/riptide-launcher/{Cargo.toml,README.md,src/main.rs,src/app.rs,src/logic.rs,src/displays.rs,src/theme.rs}`

**Consumes:** both libraries.

**Produces:** `riptide-launcher.exe`. In `logic.rs` (pure): `resolution_choices(&[Resolution]) -> Vec<Resolution>`, `play_outcome(&[Check], runtime_present) -> PlayOutcome { Blocked, NotInstalled, Start }`, `gib_to_mib` and `mib_to_gib`.

**Tests:** resolution choices are unique, largest first, and drop modes under 1280 x 720; a blocking check gives `Blocked`; no runtime gives `NotInstalled`; otherwise `Start`; GiB and MiB convert both ways.

**Verification by hand:** start the launcher, change a setting on each tab, press Play, and confirm `riptide.toml` holds the change and the launcher reports the runtime is not installed.
